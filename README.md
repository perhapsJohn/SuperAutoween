# Super Autoween (web build)

Build a crew of creepy critters, battle other players' crews, survive till dawn.
A Super Auto Pets style auto-battler, played in the browser and in the
Scareathon / Wayside Station arcade.

This repo holds only the exported web build, served by GitHub Pages:
https://perhapsjohn.github.io/SuperAutoween/

* `index.pck`: desktop pack (full-size art)
* `index.mobile.pck`: phone pack (half-size art); `index.html` picks one before
  the engine starts (`?pack=mobile` / `?pack=desktop` to force).
